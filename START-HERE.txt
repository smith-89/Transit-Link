TRANSIT LINK - INSTALL (Windows)

Keep every file in this folder together. Needs Python 3.10 or newer (python.org).

EASIEST: one command
  1. Open PowerShell in this folder (Shift + right-click > "Open in Terminal").
  2. Run:
       powershell -ExecutionPolicy Bypass -File .\install-all.ps1 -Run
  3. When it says "Starting http://localhost:8000", open that address in your browser.

OR STEP BY STEP (same result)
  powershell -ExecutionPolicy Bypass -File .\transit-link-bundle.ps1
  powershell -ExecutionPolicy Bypass -File .\transit-link-ui.ps1 -Target .\transit-link
  powershell -ExecutionPolicy Bypass -File .\transit-link-fares.ps1 -Target .\transit-link
  cd transit-link
  python -m venv .venv
  .\.venv\Scripts\Activate.ps1
  pip install -r requirements.txt
  python -m app.seed --reset --history
  uvicorn app.main:app --reload
  (then open http://localhost:8000)

The order matters: bundle first, then ui, then fares. Do not run the fares file on its own.
